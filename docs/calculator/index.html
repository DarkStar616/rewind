How this is calculated

evidence-grounded defaults · adjust everything above
  • ~44% resolve rate. On SWE-bench Verified, agents submit a patch on nearly 100% of runs but resolve only ~44% — so the default failure rate is set conservatively to 40%.
  • Failed runs cost full price. A failed trajectory is typically 50–60 model calls of exploration and looping — you pay for every token whether or not it ships.
  • Recoverable ≠ total. The recovery estimate counts only re-spend that checkpoint + replay avoids, never the original attempt. Published replay-savings figures don't exist yet; this is deliberately conservative.
  • Your numbers beat ours. Every default is a slider. Set your real team size, run volume, and provider price for a figure you can take to your own invoice.

An estimate for discussion, not a quote. Working year assumed at 250 days. Token pricing is a blended input/output rate you set yourself; actual spend depends on your provider, models, and prompt-cache usage (a discount that accrues to you, not to Rewind).
